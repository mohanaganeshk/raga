	Vector representation of text that captures their meaning;
	In PY, it just a list of numbers)
	imagine as coordinates in multi-dimensational space; 
	if 2 pieces of text are closely related in meaning, then those coordinates will be close together.
	Distance between these vectors can be calculated easily with cosine similarity or euclidian distance.

# The Difference Between Installing and Importing
Installing (pip install): Done once per environment. It downloads the package files to your venv folder.
Importing (import package): Done every time you start Python. It loads those downloaded files into your active session's memory so you can use them.

Section 8: Live Troubleshooting - Lesson Learned
Because raga.py is utilizing DefaultEmbeddingFunction(), it cuts off strings at 256 tokens (~150–200 words). If raga.py reads 7.md as one massive string or in chunks that are way too big, the embedding model silently ignores everything after the first paragraph. The second filter gets erased before it even reaches the database vector space.

To prevent truncation with ChromaDB’s default embedding model (all-MiniLM-L6-v2, which has a 256-token / ~1000-character safe limit),
